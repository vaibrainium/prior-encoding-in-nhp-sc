Goal: show on each dPCA self-projection axis whether the condition means (e.g. 2 choices) **separate** and **when** — i.e. when SC encodes choice/state/coherence — as a visual companion to the significance bar.

Decision (settled after long deliberation):
- The **thick line** = condition-balanced marginal mean projected on the demixed axis; it already is project-then-average with equal weight per condition (`np.nanmean` over non-key axes), matching the sig test and Kobak. Unchanged.
- The **shade** = analytic SEM propagated from per-cell trial stats in `fit_tw`: `SEM²_cell = s2_cell/n_cell` → condition-balanced collapse `(1/K²)Σ_cells` → projection `Σ_n w_n²·Var`. `w_n = D[marg][:,PC]`. This is the exact closed form of a per-cell trial bootstrap (validated ratio ≈0.96, gap = bootstrap ddof bias), but instant. **Bootstrap dropped** for production.
- Weighting is **condition-balanced (not trial-pooled)** to match the significance mask. Chosen over "across-non-key-condition std" because only the trial-resampling band speaks to whether the means separate.
- Data has **no 1-trial cells** (user confirmed) and `clean_dpca_data` leaves kept timepoints dense → band is exact, no special NaN handling needed.

Display/output shape (evolved after initial version, in the `plot_self_projection_ci` definition cell of 4.10):
- `plot_self_projection_ci` returns **one figure per marg** (`{marg: fig}` dict, not one combined figure) — each fig has alignments as columns, one row of subplots. Saved separately as `self_projection_ci_s.png` / `_c.png` / `_b.png`.
- Sign of each (alignment, marg, PC) panel is flipped independently via `_self_projection_flip(projections, alignment, marg, PC)` so toRF>awayRF, biased>unbiased, high coh>low coh **holds in every panel**. First version decided ONE sign aggregated across all epochs and applied it uniformly — broke down because dPCA fits each alignment's axes independently, so sign ambiguity is independent per epoch too; the aggregated version left `cue`'s `b` panel with biased<unbiased even though baseline/visual/response were correct (user caught this in the rendered figure, 2026-07-01). Per-epoch flip fixes every panel and in practice still keeps the trend consistent across epochs, since real encoding axes normally already agree — the per-epoch correction only fires on genuine axis-sign flips.
- Thin per-trial trace lines are off by default in the call (`show_thin=False`); the `show_thin` param still exists to re-enable them.
- One legend per row, drawn on the rightmost-column subplot with `bbox_to_anchor=(1.02, 0.5)` (outside the axes) — coherence levels for `s`, choice for `c`, state for `b`. `fig.tight_layout(rect=[0,0,0.88,1])` reserves margin so it isn't clipped.
- Stimulus (`s`) marg uses a notebook-local `_STIM_COLORS` sequential purple ramp (`["#cbc9e2","#9e9ac8","#756bb1","#54278f"]`, light→dark = low→high coherence), NOT `dpca_plot_utils._STIM_GREYS` — the greys were nearly indistinguishable once 4 semi-transparent overlapping CI bands blended together. Confirmed via an A/B synthetic-data comparison (same underlying noisy signal rendered both ways) that purple is clearly easier to track; user accepted "for now" (2026-07-02) — the two lightest levels (0%/6% coh) are still fairly close together, so revisit if it's still hard to read on the real data. Purple was chosen specifically to stay visually distinct from the blue/orange already used for biased/unbiased state.
